تقارب TAQARUB — نسخة جوال أولية (PWA)

هذه النسخة تعمل من المتصفح ويمكن إضافتها إلى الشاشة الرئيسية في Android.
هي ليست APK وليست شبكة اجتماعية متصلة بالإنترنت بعد.

طريقة النشر باستخدام الهاتف:
1) افتح github.com في Chrome وأنشئ حساباً إذا لم يكن لديك حساب.
2) أنشئ مستودعاً جديداً باسم taqarub-social واجعله Public.
3) من صفحة المستودع اختر Add file ثم Upload files.
4) ارفع كل محتويات هذا المجلد (index.html وstyle.css وapp.js وmanifest.webmanifest وsw.js ومجلد icons).
5) اضغط Commit changes.
6) افتح Settings ثم Pages.
7) تحت Build and deployment اختر Deploy from a branch.
8) اختر Branch: main والمجلد: /(root)، ثم Save.
9) انتظر حتى يظهر رابط الموقع في صفحة Pages وافتحه من Chrome على هاتفك.
10) من قائمة Chrome ⋮ اختر Install app أو Add to Home screen.

مهم:
- لا ترفع كلمات مرور أو بيانات شخصية إلى المستودع.
- المنشورات والإعجابات تحفظ محلياً في متصفح هذا الهاتف فقط.
- لا يوجد تسجيل دخول حقيقي أو رسائل أو مزامنة بين المستخدمين حتى الآن.
- لإطلاق شبكة اجتماعية فعلية نحتاج قاعدة بيانات ومصادقة آمنة مثل Supabase أو Firebase، ثم قواعد خصوصية وأمان.
